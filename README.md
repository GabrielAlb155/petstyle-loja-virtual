# 🐾 Pet&Style — Loja Virtual

Projeto desenvolvido como atividade prática de **Tailwind CSS**, com o objetivo de criar uma página inicial responsiva para uma loja fictícia de produtos para pets.

## 📋 Sobre o projeto

A **Pet&Style** é uma loja virtual fictícia especializada em produtos para pets, como acessórios, brinquedos e itens de conforto.

O projeto foi desenvolvido utilizando **HTML5** e **Tailwind CSS via CDN**, aplicando conceitos de responsividade, Flexbox, Grid e classes utilitárias.

## 🚀 Tecnologias utilizadas

* HTML5
* Tailwind CSS
* Flexbox
* CSS Grid
* Git
* GitHub

## 📌 Estrutura da página

O site possui as seguintes seções:

* **Header** — Logotipo e menu de navegação
* **Hero** — Apresentação da loja e chamada principal
* **Produtos** — Cards com produtos fictícios
* **Depoimentos** — Avaliações de clientes fictícios
* **Contato** — Informações de contato e formulário
* **Footer** — Rodapé da página
